WOVEN ESSENCE — WHATSAPP TEMPLATE COPY-PASTE TEXT
=================================================

Copy only the text between the BODY START / BODY END markers into
WhatsApp Manager → Account tools → Message templates.

Use the exact template names and language code shown here.
The template name, language and category must be the same in Meta and in .env.


1) OTP — AUTHENTICATION
------------------------
Template name: wovenessence_otp
Category: Authentication
Language: en_US
Button: Copy code (URL button whose URL contains {{1}})
Body variables: 2, in this exact order:
{{1}} OTP code
{{2}} purpose of the code (the app sends "Login")

BODY START
OTP Code: {{1}}. This is your OTP code for {{2}}. For your security, do not share this code.
BODY END

Sample values for Meta review:
{{1}} = 123456
{{2}} = Login

Code expiry footer: Expires in 1 minute. (must match WHATSAPP_OTP_TTL_MINUTES=1)

If you create the standard one-variable authentication template instead, set:
WHATSAPP_OTP_BODY_PARAMS=1

If you create a button-less (zero-tap) template instead, set:
WHATSAPP_OTP_INCLUDE_BUTTON=false

ENVIRONMENT MAPPING
-------------------
WHATSAPP_TEMPLATE_LANGUAGE=en_US
WHATSAPP_OTP_TEMPLATE=wovenessence_otp
WHATSAPP_OTP_BODY_PARAMS=2
WHATSAPP_OTP_TTL_MINUTES=1
WHATSAPP_ORDER_CONFIRMATION_TEMPLATE=wovenessence_order_confirmation
WHATSAPP_ORDER_SHIPPED_TEMPLATE=wovenessence_order_shipped
WHATSAPP_ORDER_DELIVERED_TEMPLATE=wovenessence_order_delivered
WHATSAPP_TEST_TEMPLATE=wovenessence_test

IMPORTANT
---------
- Do not add or remove variables; the application sends a fixed number of parameters.
  The OTP template currently has two body variables; if you replace it with a
  one-variable template, also set WHATSAPP_OTP_BODY_PARAMS=1.
- Do not use hello_world for OTP or order messages.
- All templates must share one language code because the app has a single
  WHATSAPP_TEMPLATE_LANGUAGE setting. The approved wovenessence_otp template is `en_US`,
  so create the Utility templates as `en_US` too (not `en`).
- Wait until every template status is APPROVED before enabling sending.
- Use the correct Woven Essence WABA, not the GEEKYCHAT / Excerpt account.
